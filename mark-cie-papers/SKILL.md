# CIE 试卷批改

## 确认试卷与评分标准

- 从文件名和封面识别科目代码、年份、考季、paper 和 variant；忽略下载副本的 (1)、(2) 后缀，以卷内信息为准。
- 优先从用户指定的 https://cie.craft.cn 按完整编号寻找 Mark Scheme。例如 9231_s26_qp_44.pdf 对应 9231_s26_ms_44.pdf，即 2026 May/June 的 9231/44。
- 打开评分标准并核对封面、题目数据和分值，不能只依据搜索摘要或相似文件名。
- 指定网站无法访问时简短说明，尝试 Cambridge 原始文件的可信镜像，提供实际来源；不能声称来自未访问成功的网站。
- 找不到准确版本时，明确区分独立解答和依据官方标准的批改。

## 读取作答

- 按顺序查看全部页面，包括背页、补充页、划改和续答，建立每小题与作答页的对应关系。
- 使用清晰页面图像检查手写作答、公式、图表和长答题，文字提取或 OCR 仅作辅助；遇到乱码或低分辨率时放大或重新渲染相关区域。
- 区分最终作答、明确划掉的旧解、印刷题目及已有批注。无法辨认时列出题号和具体符号，继续批改可读部分，不猜测或直接判错。

## 按得分点核对

- 逐小题核对方法、代入、计算、答案及解释或证明要求，不能只比较最终答案。
- 先识别题型和该科评分方式。数学及理科按适用的 M、A、B、DM、FT、CAO、AG、ISW 等规则给分；简答题逐项核对内容点；论述题按实际 level descriptors、assessment objectives 和整体质量评定，不机械数关键词。
- 对经济、历史、语言等长答题检查论据、分析、评价、组织和任务完成情况，仅使用该科标准实际要求。对实验题检查图表、数据处理、单位、不确定度和结论；需要实物表现、音频或其他未提供证据的部分明确限制，不假装完成评分。
- 接受等价答案及正确替代方法，除非题目指定方法。计算错误后仍检查后续方法分和标准允许的跟随分。
- 根据科目核对计算、术语、单位、图表、论证及结论；统计题检查假设、检验方向、自由度和临界值，仅按实际要求给分。
- 独立重算关键数值；标准和独立计算不一致时先复查，不悄悄替换来源。
- 遵循该科及该卷的分值规则给分，通常使用整数；逐题合计并校验总满分。作答不清时报告已确认分数和待确认部分，不编造精确总分。

## 反馈与语言

- 先给卷号、评分来源、总分或暂定范围，以及最需要修正的问题。
- 用表格覆盖每小题：题号、得分/满分、正确/部分正确/错误/待确认、简短原因。
- 每道错题说明用户的具体写法、第一处错误、为什么错、从哪里开始怎样改，并给必要推导和正确答案；区分概念错误和计算失误。
- 正确题简短确认。遇到选择题则逐一解释各选项为何正确或错误。
- 按用户明确指定的语言解释；未指定时跟随当前对话语言，可按需双语。保留必要的原卷术语；给出的示范作答使用题目要求的作答语言，区分讲解语言和考试作答语言。
- 语气自然、清楚、严谨，尊重用户的称呼和表达偏好；不预设使用者的姓名或母语。
- 归纳本卷实际出现的易错点和具体检查方法；不无依据推断能力或套用未经查证的等级线。
- 默认交付下面两份独立 PDF，并在聊天中简短列出总分、主要问题和两份文件的链接。除非用户明确更改交付要求，不需要再询问是否制作 PDF。

## 默认 PDF 交付

### 1. 逐题标分原卷 PDF

- 在用户上传的已作答试卷副本上批注，保留全部原题、手写作答、页序和续答；不修改或覆盖原始文件。
- 对每一道题及每个有独立分值的小题，在对应题目附近标注“得分/满分”；大题下有小题时，额外给出大题合计，并清楚区分合计和小题分数，避免重复计分。
- 必须在原卷第一页显眼处标注“得分 / 总分”（例如“Score: 38 / 50”），不能仅写在新增封面、评分摘要页或聊天中。空间不足时在该页扩展页边空白或适度缩放原页面以留出标分区域，不遮挡题目和作答。
- 在原卷第一页或另附评分摘要页补充卷号、实际评分来源和待确认事项。另附摘要页不能替代原卷第一页总分或各题就地标分。
- 采用清晰、统一的批改样式，将标记放在空白区域；空间不足时使用编号引线或追加批注页，不遮盖题干、图表或用户原有步骤。旋转页和跨页作答仍须正确对应题号。
- 对未作答小题按评分规则标注 0 分；对看不清或证据不足的小题标注“待确认”及具体原因，必要时给分数范围，不把无法辨认当成零分。总分相应标明暂定或范围。
- 根据需要添加简短失分提示；完整讲解放在第二份 PDF，不挤进原卷。

### 2. 错题与改进解析 PDF

- 按原卷题号排序，只收录答错、部分得分、方法或表达确有不足、以及需补充证据才能判断的小题。正确且完善的小题不重讲。
- 每个收录条目给出题号、对应原卷页码、得分/满分，准确引用或概述用户的具体写法，指出第一处错误或不足、原因、具体改法，以及必要的正确推导、示范答案或更清楚的表述。
- 对已经满分但仍有实际改进空间的答案标明“改进建议，不扣分”，区分官方失分要求和可选优化；不为了充实解析而挑无关紧要的问题。
- 明确区分概念、选法、计算、读题、表达和考试要求问题。可读性不足时说明需要确认的具体符号，不把猜测当作用户的作答。
- 对选择题，在所收录的错题或薄弱题中解释各选项的含义及正误原因；对长答题按学科评分要求给出针对性的分析或评价改进。
- 解析语言遵从用户要求，示范考试作答遵从试卷语言要求。公式、图表、原答摘录和改正后的内容要能清楚区分。
- 若整卷没有错题或实质不足，仍交付一页简短 PDF，说明未发现需讲解的问题，不编造错题。

### PDF 质量与交付

- 使用可用的 PDF 工具或 PDF skill，确保字体嵌入、中文及其他所需语言可显示、公式清晰、阅读顺序正确；保留可复制文字（原卷扫描内容除外）。
- 渲染并检查两份最终 PDF 的全部页面，修复批注错位、遮挡、越界、缺字、公式截断及表格分页问题后再交付。
- 校验原卷第一页已清楚显示得分/总分，且每个独立评分小题均有标分，解析仅收录需讲解条目，两份 PDF 的题号、分数和总分一致，分值不重复计算。
- 使用能区分用途的文件名，例如“卷号_marked.pdf”和“卷号_corrections.pdf”，保存并提供两份独立文件的链接，不能只给聊天解析或仅承诺后续制作。
- 保持试卷、手写作答、评分 PDF 和解析 PDF 私有；公开的 skill 仓库只保存流程与通用资源，不因同步 skill 而上传用户作答或批改结果。
- 若 PDF 制作确实受阻，说明具体原因和已完成部分，交付可用结果并明确缺项，不声称两份 PDF 已生成。

## 完成检查

- 确认全部题号、续答页和分值已覆盖，重新加总。
- 引用实际读过的试卷及评分标准，明确未读清或未完成的部分。
- 保留已完成进度；回复结束后不能暗示仍会自动在后台继续。
